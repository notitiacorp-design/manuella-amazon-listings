Recommandations Actions

Dans l'ordre : fiabiliser, amorcer, décider. Cliquez pour déplier chaque action.

1Mettre à jour l'adresse de retour
→

Dans Seller Central → Paramètres → Options d'expédition → Adresse de retour. Vérifiez, enregistrez. Empêche les retours bloqués, un acheteur hésitant.
Priorité : immédiate.

2Activer les 28 mises en attente
→

Fiches déjà complètes mais invisibles. Les activer expose tout le catalogue sans coût. Vérifier prix/stock avant publication.
Priorité : immédiate.

3Trancher FBM ou FBA
→

FBM (actuel)= vous expédiez vous-même. FBA = Amazon stocke & livre. FBA simplifie mais coûte un stock en entrepôt. À décider selon le volume de ventes visé.
Priorité : court terme.

4Ajouter le contenu A+
→

Recommandation n°1 Amazon pour différencier la page : images enrichies, pavés de description. Augmente le taux de conversion.
Priorité : court terme.

5Lancer une campagne Sponsored légère
→

Sans publicité, une fiche récente reste peu visible. Campagne modeste sur les perruques les plus formatées.
Priorité : avant les promos.

6Optimiser les titres SEO
→

Matière, longueur, couleur, usage dans chaque titre/recherche. Aide le référencement interne à Amazon.
Priorité : long terme.

7Décision de clôture
→

Publier aussi les 3 perruques de la maquette (Curly 14 po, Kinky 20 po, Lisse 30 po) ou se limiter aux 5 actives ? À arbitrer avec la cliente. Solde de 145 € à percevoir à la clôture.
Priorité : à valider.

Mode d'emploi Guide

Pour continuer seule en toute sécurité.

1Le site reste à vous
→

Votre site est entièrement à vous. Amazon ne prélève des frais que sur ce qui se vend sur Amazon, jamais sur votre site.

2Ajouter un produit Amazon
→

sellercentral.amazon.fr → Catégorie → Ajouter des produits → rechercher → remplir (nom, matière, longueur, couleur, photos, prix, stock) → relire → envoyer.
On ne renseigne que ce dont on est sûr.

3En cas d'écran bloquant
→

Si Amazon demande une donnée inconnue, ne pas la deviner. Faire une capture d'écran et l'envoyer : je dis quoi mettre.

4Sécurité
→

Jamais transmis : mot de passe, code SMS, coordonnées bancaires, pièce d'identité. Garder l'accès à son compte.
