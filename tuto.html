Vous pouvez avancer tranquillement, étape par étape. Si vous ne voyez pas un bouton, envoyez uniquement la capture de l'écran qui bloque.

Avant de commencer

  1. Ouvrez l'application Amazon Seller.
  2. Connectez-vous à votre compte vendeur si l'application vous le demande.
  3. Restez sur l'écran d'accueil de l'application.

Si Amazon demande un code de sécurité, saisissez-le directement dans l'application. Ne l'envoyez pas par message.

1

Ouvrir l'écran pour ajouter un produit

Dans l'application, appuyez sur ☰ Menu ou sur Produits. Cherchez ensuite Ajouter un produit ou Ajouter des produits.

Menu → Produits → Ajouter un produit

Le nom peut être légèrement différent selon la version de l'application. Si vous ne trouvez pas cette option, envoyez une seule capture de votre écran Menu.

2

Choisir une fiche

Amazon vous proposera d'abord de rechercher le produit. Recherchez le nom du produit et vérifiez attentivement :

  • le type de perruque ;
  • la longueur ;
  • la texture ;
  • la couleur ;
  • la construction de la lace.

Ne choisissez pas une fiche seulement parce que la photo ressemble. Si aucun produit n'est exactement identique, utilisez l'option pour ajouter un nouveau produit, si Amazon la propose.

3

Remplir les informations

Pour chaque fiche, reprenez les informations de la maquette. Ne complétez jamais un champ au hasard.

  • titre du produit ;
  • catégorie : perruque ;
  • longueur et texture ;
  • couleur ;
  • type de lace ou construction ;
  • photo correspondante ;
  • prix indiqué dans la maquette ;
  • stock réellement disponible ;
  • SKU ou référence interne si Amazon le demande ;
  • expédition et retours.

Si Amazon demande une information que vous ne connaissez pas, arrêtez-vous sur ce champ. Ne devinez pas : notez simplement la question.

Les points qui nous avaient posé problème

  • Ne pas mélanger les anciens produits du site avec les trois fiches de la maquette.
  • Ne pas remplacer les prix Amazon par les prix actuellement affichés sur le site.
  • Ne pas associer une photo à un autre produit.
  • Ne pas écrire « comme sur la photo » si Amazon demande une couleur précise.
  • Ne pas inventer la matière, le fabricant, l'origine, le stock, le poids ou les dimensions.
  • Ne pas créer une variation si ce sont en réalité deux produits différents.
4

Ajouter la photo dans l'application

Ajoutez la photo qui correspond à la fiche. Avant de valider, comparez-la avec la maquette :

  • Curly 14 pouces : photo Curly ;
  • Kinky Straight 20 pouces : photo Kinky Straight ;
  • Lisse 30 pouces : photo lisse 30 pouces.

Si Amazon refuse une image ou affiche une exigence particulière, ne forcez pas. Notez le message affiché.

5

Relire avant de cliquer

Avant l'envoi, vérifiez seulement ces six éléments :

  • bon produit ;
  • bonne photo ;
  • bon prix ;
  • bonne longueur ;
  • bon stock ;
  • bonne couleur.

Ensuite, validez. Amazon peut encore demander une correction ou une vérification.

Après les trois premières fiches

Pour ajouter un nouveau produit, vous reprendrez toujours le même chemin :

Menu → Produits → Ajouter un produit → rechercher → remplir → photo → relire → envoyer

La maquette et ce guide restent vos modèles. Vous pourrez refaire la méthode seule, sans devoir demander de l'aide pour chaque champ.
